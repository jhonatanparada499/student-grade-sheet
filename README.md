# Student Grade Sheet

A student transcript manager.

## Requirements
- cmake
- C/C++ compiler such as g++

## Quick Start
```
$ cmake -B build # Run only once
$ cmake --build build
$ ./build/student-grade-sheet
```

Checkout the dashboard quickly using a sample file:  
```
$ ./build/student-grade-sheet < test-input.txt
```
